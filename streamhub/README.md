# StreamHub

A personal streamer tracker with Hololive, Nijisanji, VSpo!, and Crazy Raccoon pre-loaded. Add your own streamers and custom categories.

## Setup & Deploy to GitHub Pages

### 1. Create a GitHub repo
Go to [github.com/new](https://github.com/new) and create a new **public** repo (e.g. `streamhub`).

### 2. Upload these files
Either drag-and-drop the files into the GitHub UI, or use Git:
```bash
git init
git add .
git commit -m "initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

### 3. Enable GitHub Pages
1. Go to your repo → **Settings** → **Pages**
2. Under **Source**, select **GitHub Actions**
3. Save

### 4. Done!
GitHub will automatically build and deploy the site. After ~1 minute your site will be live at:
```
https://YOUR_USERNAME.github.io/YOUR_REPO/
```

Every time you push changes to `main`, it will auto-redeploy.

## Local development
